## 六、误写原因与解决误写的具体操作步骤（2026-09-29 验证有效）

### 6.1 误写产生的原因
1. **F2 进入公式编辑器后焦点默认不在编辑框**（document.activeElement=BODY/表格），后续键盘操作作用域不可控；
2. execCommand('insertText') 插入文本只更新视图层，Enter 提交后若编辑框内容为空会被应用当作「未修改」而**保留单元格原值**；
3. execCommand('delete') 只改视图、**不触发应用输入事件**，提交无效（本次实测）；
4. **Ctrl+A 在焦点不在编辑框时会对整个表格全选 → Backspace 清空全表**（本次整表清空事故直接原因）；
5. **Enter 提交成功后自动下移一行、ArrowDown 提交会偏移一行**，连续操作导致写入错误单元格（本次误写到 data422 的原因）。

### 6.2 清除误写单元格（验证有效）
1. 名称框跳转目标格：点击 .bar-label 输入 E423（Excel 行号）→ Enter → **验证名称框显示值**；
2. 按 F2 进入编辑模式；
3. JS 聚焦编辑框：document.querySelector('#alloy-simple-text-editor').focus()，**验证 activeElement===编辑框**；
4. JS 全选编辑框内容：Range.selectNodeContents(ed) + selection.removeAllRanges/addRange；
5. **用 document.execCommand('insertText', false, '') 替换选区（关键：触发应用 input 事件；不要用 execCommand('delete')）**；
6. 验证编辑框 innerText 为空、焦点仍在编辑框；
7. 按 Enter 提交；
8. JS API 回读验证目标格及前后行（getCellDataAtPosition）确认已清除、相邻行未受影响。

### 6.3 写入正确值（验证有效）
