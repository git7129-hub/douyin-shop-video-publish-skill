# 配置引导（CONFIG-GUIDE）· 抖店短视频自动发布技能

> 面向**新部署者**的手把手配置指南。照做即可在本机跑起来。全部用时约 15-20 分钟。
> 如果你只想用别人的现成配置，只需完成「第一步」并把对方的 `config.json` 放到技能目录即可。

---

## 第一步：安装技能（2 分钟）

1. 找到你所用客户端（支持 Agent Skills 的豆包 / 同类客户端）的 **skills 根目录**；
   - 常见位置：客户端数据目录下的 `.skills`（豆包）或 `~/.agents/skills`；
   - 不确定时，在客户端里问一句「我的 skills 根目录在哪」即可定位。
2. 把本仓库 `skills/douyin-shop-video-publish/` **整个目录**复制进去：
   ```
   skills/
   └── douyin-shop-video-publish/
       ├── SKILL.md
       ├── config.example.json
       ├── CONFIG-GUIDE.md      ← 本文件
       └── README.md
   ```
3. 确认技能被识别：在客户端提问「列出 douyin-shop-video-publish 技能并读它的配置项」，能读到 SKILL.md 即安装成功。

## 第二步：创建 config.json（1 分钟）

打开命令行（Windows 用 PowerShell），进入技能目录，执行：

```powershell
cd <你的技能目录路径>\douyin-shop-video-publish
Copy-Item config.example.json config.json
```

之后所有配置只改 `config.json`（**不要改 SKILL.md 里的示例**）。

## 第三步：逐字段配置（8-10 分钟）

用任意文本编辑器（推荐 VS Code）打开 `config.json`，逐项填写：

### 3.1 页面地址（一般不用改）

| 字段 | 填什么 | 说明 |
|---|---|---|
| `pages.home` | 抖店商家后台首页 | 默认即可：`https://fxg.jinritemai.com/ffa/mshop/homepage/index` |
| `pages.publish` | 短视频运营页 | 默认即可：`https://fxg.jinritemai.com/ffa/content-tool/short-video` |

### 3.2 文档（必填，最核心）

| 字段 | 填什么 | 去哪拿 |
|---|---|---|
| `sheets.task_sheet_url` | **任务表**（腾讯文档/在线表格）完整 URL | 打开你的任务表 → 浏览器地址栏复制 |
| `sheets.product_sheet_url` | **商品ID在线表**（含 型号→商品编号→话题 列）完整 URL | 打开你的商品ID表 → 地址栏复制 |
| `sheets.task_api_js` | 任务表读取用的 JS API | 腾讯文档保持默认：`window.SpreadsheetApp.workbook.worksheetManager.getSheetList()[0]`；其他平台按平台脚本改 |

> 任务表至少要包含：视频名（A）、店铺（D）、发布时间（E）、备注（F），列位置可在技能规则里调整。
> 商品ID表至少要包含：店铺、型号、商品编号、话题，每型号一行。

### 3.3 本地路径（必填）

| 字段 | 填什么 | 说明 |
|---|---|---|
| `paths.video_dir` | 视频暂存文件夹 | 技能会把下载的视频放这里；目录需真实存在，如 `D:\douyin_shop_video_publish\temp file\` |
| `paths.banned_words_xlsx` | **违禁词表**（xlsx）路径 | 表格格式：一列即可，每行一个违禁词；不配置则技能不会做违禁词检查 |
| `paths.product_id_xlsx` | 商品ID本地表路径 | 可选（有在线表可留空）；格式：店铺/型号/商品编号 三列 |
| `paths.run_log_dir` | 运行记录存放目录 | 如 `E:\豆包项目\抖店发布`；不配置则跳过每日记录 |

### 3.4 店铺清单（必填）

| 字段 | 填什么 |
|---|---|
| `shops` | 你抖店账号下所有子店铺名，JSON 数组，如 `["采寻","蓝讯","码客"]`。技能用它做店铺分组、并发调度和切换校验 |

> 店铺名必须与抖店后台右上角显示的名称**完全一致**（含空格/大小写）。

### 3.5 规则参数（按需）

| 字段 | 默认 | 含义 |
|---|---|---|
| `rules.max_concurrency` | `2` | 同时处理几个店铺（1-5） |
| `rules.huan_yihuan_max` | `5` | 违禁词自动「换一换」上限 |
| `rules.timed_hours_gap` | `2` | 同店相邻视频定时发布间隔（小时） |
| `rules.publish_window` | `""` | 当天允许的发布时间窗口（如 `"23:59"`）；留空=不限 |

### 3.6 GitHub 同步（可选）

| 字段 | 填什么 |
|---|---|
| `sync.repo` | 你的私有仓库 `owner/repo`（默认指向本技能仓库） |
| `sync.branch` | `main` |

不打算同步运行记录到 GitHub 就留默认，不影响发布功能。

## 第四步：准备资产（2 分钟）

1. **违禁词表**：准备一个 xlsx，Sheet1 第一列每行一个违禁词（如：超、最、第一、顶级、必备、神器、微信、电话号、二维码、网址）。路径填到 `paths.banned_words_xlsx`。
2. **商品ID表**：确保在线表/本地表有每型号的 店铺+型号+商品编号（+话题栏）。发布时技能按「店铺+型号」精确匹配，**匹配不到或匹配到多个会暂停等你处理，绝不自动猜编号**。

## 第五步：登录（3 分钟）

1. **抖店**：让 Agent 打开 `pages.home` → 你会看到企业微信扫码 → 扫码登录主账号 → 确认右上角能显示店铺名和「切换组织/店铺」。
2. **任务表平台（腾讯文档）**：打开 `sheets.task_sheet_url` → 登录 → 确认能读到表格数据。
3. **GitHub（可选）**：仅同步运行记录需要，`gh auth login --web` 授权一次即可。

## 第六步：验证配置（2 分钟）

让 Agent 执行一次**「全表扫描」**（技能流程第一步）。成功标志：

- 能列出任务表全部行数与各店铺任务数；
- 能区分：已完成（E 列有发布时间）、待处理（E 列空）、测试/违规（备注标记）。

出现任何一步报错，对照「常见问题」。

## 第七步：首次运行

按 SKILL.md「二、核心执行流程」启动：Agent 会先全表扫描 → 按店铺并发建队 → 逐店处理。**第一次跑建议只配 1 个店铺、只跑 1 条任务**试通全流程，再放开并发。

## 常见问题（FAQ）

| 现象 | 原因与处理 |
|---|---|
| 「读不到任务表数据」 | ① 未登录任务表平台；② `task_sheet_url` 无访问权限（让对方把文档分享给你）；③ `task_api_js` 与你平台不符 |
| 「商品查不到 / 多个匹配」 | 技能会**暂停人工处理**——请手动指定商品编号，或在商品ID表补全该型号再继续；禁止让技能猜 |
| 「描述总是含违禁词」 | 检查违禁词表是否包含过宽词汇（如「太方便」也会被拦时，把该词从表中删除）；或换一换达到上限后按 SOP 查商品ID表话题栏 |
| 「话题 #xxx 加不进去」 | 必须**输入 #话题 → 等待下拉 → 选择第一个匹配**，不能纯文本输入；下拉未出现通常是输入过快，稍等再输 |
| 「定时时间总是被平台改」 | 抖店只允许未来 2 小时-14 天定时；早于最早可定时会被平台自动调整——**以平台显示时间为准回填**，属正常 |
| 「上传视频失败/停在 00:00」 | 页面重渲染后需重走发布面板；确认视频文件完整（非 `.crdownload`） |
| 「同步到 GitHub 失败」 | 本机 git 443 可能被网络拦截——同步脚本已改用 gh API 直传并自动重试；确认 `gh auth status` 已登录 |

## 安全提醒

- `config.json` 含你的文档链接与本地路径，**属于私有信息**；分享技能时只分享除 config.json 外的文件；
- 不要把你的任务表/商品ID表链接提交到任何公开仓库。
